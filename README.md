# National Institute of Chemistry of Slovenia — Conference Presentation Package

This repository contains a bilingual, academic conference presentation introducing the National Institute of Chemistry of Slovenia (NIC / Kemijski inštitut) to university and industry leaders.

## Contents

- `PPT_EN.md` — English slide-by-slide text, ready to copy into PowerPoint
- `PPT_BILINGUAL.md` — English–Chinese slide text
- `SPEAKER_NOTES_EN.md` — complete English speaker script for approximately 45 minutes
- `DESIGN_AND_SOURCES.md` — visual guidance, image/chart suggestions, and source register

## Intended use

The deck is designed for an academic conference whose purpose is to open international academic and industrial collaboration. It deliberately avoids unverified current statistics; institutional numbers, project names, instrument access conditions, and partner examples should be confirmed with NIC before final publication.

## Recommended final checks

1. Confirm current institute structure, research-group names, and leadership.
2. Replace suggested visuals with images cleared by NIC.
3. Add the presenter’s affiliation and contact details.
4. Confirm any current China–Slovenia cooperation examples directly with the relevant institutions.
5. Apply the source notes in `DESIGN_AND_SOURCES.md` to the final slides.
